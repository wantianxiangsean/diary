# 每日日记 · 1% 精进

一个单文件网页版日记本，版式按「年目标 / 月目标 / 周目标」模板复刻，支持整篇回退与选中文字上色。

## 使用

双击 `index.html` 用浏览器打开即可（不需要联网、不需要安装任何东西）。

## 功能

- 顶部可按日期前后翻页，每天单独存档；新日期一律从空白开始，不会自动带上别天的内容
- **复制昨天**：顶部按钮，点一下会把最近一份**真正填写过**的记录（往回最多 30 天，自动跳过空白/只剩模板表头的那些天）的内容填进当前这篇——日期自动换成当天、「好习惯检视」和「清晨自问」的勾选清零，其余照抄；当前这篇已经写过内容时会先问一次，且随时可以用「上一步」撤销。往前 30 天都没有填写过的记录时会提示找不到，不会填入空白内容
- **上一步 / 下一步**：顶部两个图标按钮 `↶` `↷`，整篇回退/重做，避免误操作（`Ctrl/⌘ + Z` 回退，`Ctrl/⌘ + Y` 或 `Ctrl/⌘ + Shift + Z` 重做）
- **选中文字改颜色**：用鼠标选中一段文字后，旁边浮现色板 `默认 · 黑 · 红 · 橙 · 绿 · 蓝`，点色块只给选中的那一段上色；点「默认」只去掉选中部分的颜色
- 「示例」一键铺满模板样例，「清空」清空当天
- 「导出 .md」把当天日记导出为纯文本 Markdown：小节、表格、清单都是标准 Markdown 语法，不含任何 HTML 标签，文字颜色不导出
- 打印走浏览器自带的 `Ctrl/⌘ + P`：自动隐藏工具栏，保留配色与边框，输出 A4 打印稿
- `Ctrl/⌘ + S` 立即保存

## 版式

- 每小节一条蓝色标题横幅；表格只有表头/子标题是浅黄底（`#F8E19B`），其余单元格一律白底 + 灰色网格线
- 「2025年1月份关键目标：」「1月份第4周」是红底白字的横幅（`#EB1E1E`）；座右铭是黄底红字（`#FBFF00`）
- A–I 每一节都套一圈浅灰外框，蓝条与边框左右齐平
- 清晨自问、工作、生活三处列表的行与行之间有浅灰分割线

## 表格编辑

月度表（本月关键目标）和周表（本周目标）各自右上角有一个「表格编辑」开关：

- 关闭时就是普通打字状态
- 打开后表格转为只读，鼠标拖过一片单元格即可框选（蓝色高亮），选区旁浮现工具条：**合并 / 拆分 / 清除内容 / 插入行 / 删除行**（按需求不含列操作）
- 合并按「从上到下、从左到右」顺序把文字换行拼接，保留在左上角格子里，不丢内容，颜色也保留
- 拖动表头格子右边缘 = 调整列宽（相邻列自动补偿，总宽不变）
- 拖动行下边缘 = 调整行高；双击行把手恢复自动高度
- 表格下方保留「＋ 添加一行 / ＋ 添加一组类别 / ＋ 添加优先事项 / ＋ 添加其他目标」按钮；合并与尺寸都按日期保存在本机，刷新或切换日期后再回来依然保留

## 发布到公网（Netlify）

这个页面是纯静态单文件，没有构建步骤，三种发布方式任选：

1. **最快**：打开 [app.netlify.com/drop](https://app.netlify.com/drop)，把整个 `dairy` 文件夹拖进去，几秒后就会得到一个 `https://xxx.netlify.app` 公网地址。
2. **Netlify CLI**：`npm i -g netlify-cli`，然后在本目录执行 `netlify deploy --dir . --prod`。
3. **接 Git**：把文件夹推到 GitHub，在 Netlify 选 "Add new site → Import an existing project"，Build command 留空，Publish directory 填 `.`。

仓库里已经放好两份配套文件：

- `netlify.toml`：publish 目录为 `.`、不执行构建、附带基础安全响应头与 `X-Robots-Tag: noindex`
- `robots.txt`：阻止搜索引擎收录

**发布前请注意**：日记正文保存在每台设备自己的浏览器里（localStorage），发布到公网只是把“本子”放上网——你自己写的内容不会上传，也不会在手机和电脑之间同步。另外，新访客第一次打开时页面会用内置示例内容预填一遍（里面有同事姓名、目标等），如果要公开分享，建议先把预填示例去掉或换成占位文字。
