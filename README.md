# 每日日记 · 1% 精进

一个单文件网页版日记本，包含每日日记、每周周报与每月月报。日记版式按「年目标 / 月目标 / 周目标」模板复刻，周报按叶武滨时间管理周报模板复刻，月报按易效能月度检视表复刻，支持整篇回退与选中文字上色。

## 使用

双击 `index.html` 用浏览器打开即可（不需要联网、不需要安装任何东西）。

## 功能

- 顶部可按日期前后翻页，每天单独存档；新日期一律从空白开始，不会自动带上别天的内容
- 顶部「日记 / 周报 / 月报」切换：周报按 ISO 周存档，月报按月存档；都可前后翻页或直接选择周次/月份
- **复制昨天**：顶部按钮，点一下会把最近一份**真正填写过**的记录（往回最多 30 天，自动跳过空白/只剩模板表头的那些天）的内容填进当前这篇——日期自动换成当天、「好习惯检视」和「清晨自问」的勾选清零，其余照抄；当前这篇已经写过内容时会先问一次，且随时可以用「上一步」撤销。往前 30 天都没有填写过的记录时会提示找不到，不会填入空白内容
- **复制上周**：周报模式下按钮会自动变成「复制上周」，往回最多找 52 周，只复制真正填写过的周报，周次和日期范围自动更新
- **复制上月**：月报模式下按钮会自动变成「复制上月」，往回最多找 12 个月，只复制真正填写过的月报，月份自动更新
- **上一步 / 下一步**：顶部两个图标按钮 `↶` `↷`，整篇回退/重做，避免误操作（`Ctrl/⌘ + Z` 回退，`Ctrl/⌘ + Y` 或 `Ctrl/⌘ + Shift + Z` 重做）
- **选中文字改颜色**：用鼠标选中一段文字后，旁边浮现色板 `默认 · 黑 · 红 · 橙 · 绿 · 蓝`，点色块只给选中的那一段上色；点「默认」只去掉选中部分的颜色
- **手动调节字号**：选中文字后，浮动工具里的 `A− / A+` 调整选中文字；也可以点进任意输入框，用顶部 `A− / A+` 调整整段字号。字号按记录保存，刷新、切换日期/周次/月份后仍保留
- **空内容提示**：删除输入框或表格单元格里的全部文字后，会自动恢复该字段原来的灰色提示文字
- **周目标确认**：日记页「周目标」表格每条目标左侧有确认框，勾选后该条目标文字显示删除线；状态随当天记录保存
- **多终端适配**：电脑、平板和手机自动调整布局；手机端工具栏收进两排，字号、复制、示例、清空、备份、导出等收在 `⋯` 里点开，日记表格可在表内左右滑动，目标条目和清晨自问改为纵向排列
- **回看与搜索**：顶部「🔍 回看」打开面板，可以搜索全部日记、周报、月报里的文字（命中的词高亮），不输入时列出「最近写过」的时间线；点任意一条直接跳到那一天的日记 / 那一周 / 那一个月。空白记录不会出现在列表里
- **周报草稿**：周报页顶部「🧩 根据本周日记生成草稿」会把本周 7 天日记里的高能要事、成功&反思、健康/学习/人际/财务分项汇总，填进还没有内容的格子里（三只青蛙、五色回顾、反思、目标检视），已有内容不会被覆盖，生成后可以继续手改，也能用「上一步」整篇撤回
- **月报草稿**：月报页顶部「🧩 根据本月周报生成草稿」把本月各周报的三只青蛙、五色回顾、反思、下周要事汇总成月报草稿，填入八大关注（健康/家庭/觉察/成长）、本月三只青蛙、卡点与教训、下月三只青蛙；同样只填空位、可整篇撤回
- **本机全量备份**：「☁ 备份」面板里的「导出全部（.json）」把全部日记、周报、月报打成一个文件下载到本机，不需要 token；「从 .json 导入」读回来，默认跳过本机已有的同名记录（勾上「恢复时覆盖本机同名记录」才覆盖）
- **存储写满会提示**：浏览器 localStorage 写不进去时会明确提示，并引导先去导出全部
- 「示例」一键铺满模板样例，「清空」清空当天、当前周或当前月
- 「导出 .md」把当天日记、当前周报或当前月报导出为纯文本 Markdown：小节、表格、清单都是标准 Markdown 语法，不含任何 HTML 标签，文字颜色和字号不导出
- 打印走浏览器自带的 `Ctrl/⌘ + P`：自动隐藏工具栏，保留配色与边框，输出 A4 打印稿
- `Ctrl/⌘ + S` 立即保存

## 云端备份（GitHub）

顶部「☁ 备份」按钮打开备份面板，可以把日记、周报和月报写进你自己的 GitHub 仓库：日记每天一个文件 `diary/YYYY-MM-DD.json`，周报每周一个文件 `weekly/YYYY-Www.json`，月报每月一个文件 `monthly/YYYY-MM.json`。每次备份是一次 Git 提交，所以 GitHub 上留着完整的历史，改错了能回滚。

准备两步（只用做一次）：

1. 在 GitHub 上新建一个**私有**仓库（例如 `diary-backup`）。免费账号也能建私有仓库——备份不需要 Pages，所以私有完全够用。
2. 生成一个**只授权这个仓库**的细粒度 token（Settings → Developer settings → Personal access tokens → Fine-grained tokens），权限只给 `Contents: Read and write`。

然后在面板里填：`仓库`＝`用户名/仓库名`，`Token`＝刚生成的串，勾上「记住（存本机）」再点「保存设置」。

面板里的按钮：

- **立即备份本篇**：把当前日期、当前周次或当前月份这一篇推到云端
- **备份全部**：把本机 localStorage 里所有日记、周报和月报逐个推上去
- **从云端恢复**：读回云端 `diary/`、`weekly/` 和 `monthly/` 下所有文件。本机已有的同名记录默认**跳过**（不会覆盖你正在写的内容），需要覆盖时先勾上「恢复时覆盖本机同名记录」
- **自动备份**：勾选后，停止编辑约 10 秒自动推一次；切换到别的标签页或最小化窗口时也会立刻补一次。内容没变化时不会重复提交

两点提醒：token 存在你这台浏览器的 localStorage 里（不勾「记住」则关掉页面就没了），所以别在公用电脑上勾选；另外**不要用公开仓库**做备份，否则日记内容任何人都能读到（Pages 那个公开仓库只放页面代码，不含你的日记）。

## 数据存在哪

日记、周报和月报正文只存在你本机浏览器的 `localStorage` 里（按域名隔离，线上站点和本地文件是两套），不会自动上传。清浏览数据、换浏览器、换电脑都会让它消失，所以建议配合上面的云端备份，或用「☁ 备份」→「导出全部」定期存一份 `.json` 到本机。面板里同时会显示本机已存多少篇、占多少空间，以及上次云端备份的时间。

## 版式

- 每小节一条蓝色标题横幅；表格只有表头/子标题是浅黄底（`#F8E19B`），其余单元格一律白底 + 灰色网格线
- 「2025年1月份关键目标：」「1月份第4周」是红底白字的横幅（`#EB1E1E`）；座右铭是黄底红字（`#FBFF00`）
- A–I 每一节都套一圈浅灰外框，蓝条与边框左右齐平
- 清晨自问、工作、生活三处列表的行与行之间有浅灰分割线

## 表格编辑

月度表（本月关键目标）和周表（本周目标）各自右上角有一个「表格编辑」开关：

- 关闭时就是普通打字状态；在格子里拖拽照常选文字，**一旦拖到别的格子就自动转成整片框选**（蓝色高亮），选区上方浮现色板与 `A− / A+ / 清空`——可以一次给这片格子整体上色、去色、调字号或清空内容
- 打开后表格转为只读，鼠标拖过一片单元格即可框选（蓝色高亮），选区旁浮现工具条：**合并 / 拆分 / 清除内容 / 插入行 / 删除行**（按需求不含列操作）
- 合并按「从上到下、从左到右」顺序把文字换行拼接，保留在左上角格子里，不丢内容，颜色也保留
- 拖动表头格子右边缘 = 调整列宽（相邻列自动补偿，总宽不变）
- 拖动行下边缘 = 调整行高；双击行把手恢复自动高度
- 表格下方保留「＋ 添加一行 / ＋ 添加一组类别 / ＋ 添加优先事项 / ＋ 添加其他目标」按钮；合并与尺寸都按日期保存在本机，刷新或切换日期后再回来依然保留

周报和月报里的表格也有同样的「表格编辑」开关。它们只调整列宽和行高，不提供合并 / 插入 / 删除；拖动列边框或行边框即可调整，双击行把手恢复自动高度。尺寸按周/按月保存在本机，并随对应记录一起备份到云端。表格里的文字可以点进去后用顶部 `A− / A+` 单独调整字号；普通状态或「表格编辑」下都可以用鼠标拖动框选多个单元格，选区上方浮现和日记表格相同的浮条：整片上色 / 去色、`A− / A+` 调字号、清空内容。

手机上这三处表格的拖拽都留给横向滚动，要框选先打开「表格编辑」。

## 周报结构

- 周次 / 日期范围
- 一、本周三只青蛙（计划要事、实际完成、完成度、未完成原因、补救）
- 二、本周五色日程回顾（工作、健康、学习成长、家庭人际、个人要事）
- 三、本周反思与改进（亮点、不足、时间浪费、下周改进动作）
- 四、下周三只青蛙（要事、日期、开始时间、时长、结果标准）
- 五、下周日程安排（周一至周日 × 上午/下午/晚上）
- 六、月度 / 年度目标检视（六个维度）
- 本周一句话总结

## 月报结构

- 时间 / 本月关键词
- 一、对照年度目标（本月进度% / 说明）
- 二、八大关注回顾（健康、家庭、效能、财富、休闲、觉察、社交、成长）
- 三、本月三只大青蛙（最重要成果）
- 四、本月卡点与教训（现象 / 事实、原因 / 对策）
- 五、下月三只大青蛙（优先要事）
- 六、感恩

## 发布到公网（Netlify）

这个页面是纯静态单文件，没有构建步骤，三种发布方式任选：

1. **最快**：打开 [app.netlify.com/drop](https://app.netlify.com/drop)，把整个 `dairy` 文件夹拖进去，几秒后就会得到一个 `https://xxx.netlify.app` 公网地址。
2. **Netlify CLI**：`npm i -g netlify-cli`，然后在本目录执行 `netlify deploy --dir . --prod`。
3. **接 Git**：把文件夹推到 GitHub，在 Netlify 选 "Add new site → Import an existing project"，Build command 留空，Publish directory 填 `.`。

仓库里已经放好两份配套文件：

- `netlify.toml`：publish 目录为 `.`、不执行构建、附带基础安全响应头与 `X-Robots-Tag: noindex`
- `robots.txt`：阻止搜索引擎收录

**发布前请注意**：日记正文保存在每台设备自己的浏览器里（localStorage），发布到公网只是把“本子”放上网——你自己写的内容不会上传，也不会在手机和电脑之间同步。另外，新访客第一次打开时页面会用内置示例内容预填一遍（里面有同事姓名、目标等），如果要公开分享，建议先把预填示例去掉或换成占位文字。
